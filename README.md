# Tic Tac Toe

A simple two-player terminal-based Tic Tac Toe game built with Python using Object-Oriented Programming.

## Features

* Two-player gameplay
* Player name and symbol selection
* Input validation
* Win detection
* Draw detection
* Game restart option
* Simple terminal-based interface

## Technologies

* Python
* Object-Oriented Programming

## Project Structure

The project is organized into several classes:

* `Player` — Handles player names and symbols
* `Menu` — Handles the main menu and end-game menu
* `Board` — Manages the game board and player moves
* `Game` — Controls the game flow, turns, win/draw detection, and restarting

## How to Run

Run the following command:

```bash
python main.py
```

## Gameplay

The game starts with a menu where you can choose to start the game or quit.

Each player enters their name and chooses a single-letter symbol. Players then take turns selecting an available position on the board.

The game ends when a player wins or when all positions are filled, resulting in a draw.
